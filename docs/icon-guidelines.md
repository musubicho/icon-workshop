# 图标设计规范

Nyatabi 图标的绘制规则。画新图标或改旧图标前读一遍，提交前按「自检」逐条过。

## 画布与线条

- 画布 `viewBox="0 0 48 48"`，App 里按 24pt 显示，线宽和间距都会减半。
- 根元素统一写成：

  ```svg
  <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 48 48" width="48" height="48" fill="none" stroke="#453D35" stroke-width="2.4" stroke-linecap="round" stroke-linejoin="round" data-category="饮食">
    <title>拉面</title>
    <desc>可选，一句话描述画面。</desc>
  ```

- 线宽只用 2.4，不加粗也不变细。
- 端点和拐角都是圆头。计算间距时，圆头会让线端多伸出 1.2。
- 只用 `path`、`circle`、`ellipse`、`rect`、`line`、`polyline`、`polygon`、`g`，不写 `style`、CSS、滤镜或外部引用（`validate.ts` 会拒绝）。

## 颜色

| 角色 | 浅色 | 深色（导出时自动替换） | 用途 |
| --- | --- | --- | --- |
| 墨 | `#453D35` | `#EFE4D7` | 主轮廓，写在根元素上 |
| 朱红 | `#C23B22` | `#FF7A5C` | 主强调：一处关键细节 |
| 金 | `#8A6200` | `#E0A526` | 次强调：装饰、刻度、热气 |
| 抹茶绿 | `#53765A` | `#9FBC91` | 只用于植物、茶、成功状态 |

- 轮廓用墨色，彩色只画细节。整枚图标就是一个状态色的除外，比如 `done`、`failed`。
- 浅色填充只用同色，`fill-opacity` 取 `.12`～`.16`，并写 `stroke="none"` 或与描边同色。
- 实心填充只用于直径 5 以内的小圆点，比如眼睛、指针轴心。

## 间距

单色模式（`currentColor`、iOS 模板图）会把所有颜色换成同一种颜色。原色里看着还行的压线，到了单色下就糊成一块。所以下面这几条比好不好看更优先。

1. **彩色线不碰墨线，没有例外。** 不压在墨线上，不穿过墨线，端点也不落在墨线上。挂在物体上的部件（提手、顶灯、引脚、底座）要么和它所在的物体同色、直接相连，要么换成彩色并留出缝隙。
2. **不相连的两条线，中心线至少相距 3.6**，也就是可见缝隙至少 1.2（24pt 下是 0.6pt）。同色、异色都一样，端点也算在内。
   - 线端到直线的距离按中心线算，圆头已经包含在这 3.6 里。
   - 线端到圆或弧的距离 = 端点到圆心的距离 − 半径，同样要 ≥ 3.6。
3. **被挡住的物体要断开。** 后面的人、后面的纸、篮子里的萝卜，都在前面物体的轮廓前 3.6 处收笔，不要接到前面的轮廓上。
4. **交叉要交代前后。** 两条线必须相交时（链环、删除斜杠），被压在下面的那条在交点两侧断开，断口离上层线的中心线至少 3.6。斜杠穿过的彩色部件也一样要断开。
5. **空间不够就不放。** 一条线放进轮廓里，两侧各要 3.6，所以容器内宽至少 7.2。机翼、瓶颈这类窄处放不下，就去掉那条线或挪到轮廓外面。
6. 同色、同一物体内部的结构线可以相接，比如日历的表头线、地球的经纬线。
7. 浅色填充不受间距限制，但不要超出它所在的轮廓。

## 形状

- **箭头整支同色。** 箭头和箭杆要么都是墨色，要么都是彩色。箭头的两翼对称地落在箭杆末端的切线两侧，弧形箭头也一样。
- **剪影的拐角要有圆角。** 人物的肩膀、盘子、底座这类「曲线落在平底上」的拐角，用 `q` 收一个半径约 2 的圆角，不要直角相接。星形、齿轮、勾、叉这类本来就带尖角的形状除外。
- **内部细节放在视觉中心。** 卡片、标签、徽章里的横线和图案，以形状扣掉孔洞、挂绳之后剩下的面积为准居中，不要偏到一角。
- 徽章叠在主体上时（日历加号、卡片充值），主体轮廓在徽章周围断开，和规则 4 一样。

## 常见错误

| 错误 | 例子（已修） | 改法 |
| --- | --- | --- |
| 彩色半径的端点落在圆周上 | `stats` | 两端各收进 3.6 |
| 彩色图形横穿墨色边线 | `wallet`、`other` | 墨线在穿过处断开 |
| 刻度骑在表盘弧线上 | `usage` | 刻度整体收进弧线内侧 |
| 两个环直接叠在一起 | `link` | 一处断墨线、一处断红线，做出环扣 |
| 彩色提手、顶灯立在墨线上 | `trash`、`taxi`、`guest` | 提手和盖子同色并与桶身分开；顶灯悬空；挂扣改墨色 |
| 后面的人接在前面的人身上 | `nearby` | 后面的人在前面轮廓前收笔 |
| 肩线和底边直角相接 | `nearby`、`profile`、`invite` | 收圆角 |
| 箭头和箭杆不同色，箭头没对准弧线 | `refresh`、`undo` | 整支同色，箭头沿切线 |
| 线端离边框只剩不到 1 | `filter`、`passport`、`train` | 收短到 3.6 |
| 窄条里硬放彩色线 | `plane` | 去掉，或移到轮廓外 |
| 横线偏在标签一角 | `other` | 挪到标签面积的视觉中心 |

## 自检

1. 在站点里切到**单色**，看有没有地方糊成一块。
2. 切到 **24 px** 预览，看有没有线贴在一起。
3. 对照「间距」和「形状」，检查每个彩色元素的两个端点、每个拐角和每支箭头。
4. 改完把整套导出到 App，见 README 的「Use on iOS」。`MusubiIcons.xcassets` 只从这里导出，不在 App 仓库里手改。
